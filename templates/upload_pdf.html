Загрузите PDF-файл для обработки

Перетащите документ в область загрузки или выберите его вручную. После отправки файл будет принят системой и использован для дальнейшей обработки.

Поддерживаются только PDF-файлы
Быстрая отправка без лишних шагов
Результат можно использовать сразу

Что происходит после загрузки

  1. Файл принимается системой и проверяется на корректность.
  2. Документ передаётся в модуль обработки.
  3. После успешной загрузки вы получите дальнейшие результаты по сценарию приложения.

Файл не выбран

Подсказка: убедитесь, что документ открыт и не повреждён. Если файл слишком большой, подождите завершения отправки.

Как загрузить файл

  • 1 Выберите PDF-документ с помощью кнопки или перетащите его в область загрузки.
  • 2 Проверьте название файла внизу блока загрузки.
  • 3 Нажмите «Загрузить файл» и дождитесь обработки.

Рекомендации

  • Используйте только файлы с расширением .pdf.
  • Переименуйте документ, если в нём есть специальные символы.
  • Если загрузка не удалась, попробуйте отправить файл ещё раз.
